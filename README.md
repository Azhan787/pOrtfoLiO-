## Getting Started

Want to explore or run the project locally?

### 1. Clone the repository

```bash
git clone https://github.com/Azhan787/Muhammad-Azhan-Portfolio.git
```

### 2. Open the project folder

```bash
cd Muhammad-Azhan-Portfolio
```

### 3. Run the website

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No build command is required for a standard HTML, CSS, and JavaScript version of the portfolio.

## Deployment

The live portfolio is hosted on Vercel.

To deploy your own copy, import the repository into Vercel and configure the project according to its actual file structure. For a static website, ensure the homepage is available as `index.html` in the configured output directory.
